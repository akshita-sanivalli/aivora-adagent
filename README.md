# AdAgent

An AI-powered marketing campaign prototype built with Python, Streamlit, and Google Gemini.

## Features
- AI-generated advertising copy
- Campaign strategy recommendations
- Simulated campaign analytics
- Promotional poster display and download

## Run locally
Install dependencies with:
pip install -r requirements.txt

Run the app with:
streamlit run app.py

## Limitations
Campaign metrics are simulated. Live advertising integrations and automatic publishing are not implemented.
