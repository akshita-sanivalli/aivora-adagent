# Aivora AdAgent

**An AI-powered marketing campaign generator using multiple AI agents.**

## Overview

Aivora AdAgent helps users create marketing campaigns for products, services, businesses, events, and applications. Users can describe their campaign, select a target audience, define a goal and budget, and choose marketing channels.

## AI Agents

- **Creative Agent:** Generates marketing content and campaign ideas.
- **Marketing Strategy Agent:** Suggests campaign strategies and channel-specific approaches.
- **Performance Optimization Agent:** Provides optimization recommendations and simulated campaign analytics.

## Features

- User-defined campaign requests
- AI-generated marketing content
- Marketing strategy recommendations
- Simulated campaign analytics
- Poster content and design brief generation
- Downloadable poster design brief

## Technology Stack

- Python
- Streamlit
- Google Gemini API
- Python concurrent execution

## Run Locally

1. Clone this repository.
2. Create and activate a Python virtual environment.
3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the application:

   ```bash
   python -m streamlit run app.py
   ```

5. Enter your Gemini API key in the application sidebar.

## Important Notes

- A valid Gemini API key and internet access are required for AI features.
- Analytics are simulated; live advertising performance data is not connected.
- Publishing integrations are not connected.
- Poster generation currently produces poster content and a design brief, not a generated image.
